# انتشار نسخه، به‌روزرسانی امضاشده و ماتریس تست (M6)

## به‌روزرسانی امضاشده‌ی ایجنت

ایجنت فقط از زیپی به‌روز می‌شود که با **کلید انتشار شما** امضا شده باشد. Studio هرگز به کلید خصوصی نیاز ندارد؛ زیپ امضاشده را همراه خود دارد و دقیقاً همان بایت‌ها را می‌فرستد.

```
npm run release:keygen -- <پوشه‌ای بیرون از مخزن>   # یک بار: کلید خصوصی آنجا، کلید عمومی در agent/.../UpdateKey.php
WPM_RELEASE_KEY=<پوشه>/wpm-release-private.pem npm run release
```

`npm run release` فایل‌های `dist/wpm-agent.zip` و امضایش `dist/wpm-agent.zip.sig` (Ed25519 روی `"wpm-agent-update\n" + sha256`)، `dist/wpm-agent.version`، `dist/wp-mcp-bridge.zip` و `dist/SHA256SUMS` را می‌سازد و ایجنت امضاشده را کنار Studio می‌گذارد. فایل‌های `dist/` را به‌عنوان Release گیت‌هاب منتشر کنید.

در صفحه‌ی هاست‌ها، ایجنتی که قدیمی‌تر از نسخه‌ی Studio باشد دکمه‌ی **به‌روزرسانی ایجنت** دارد. ایجنت: امضا را با کلید عمومی داخل خودش تأیید می‌کند، هر چیزی را که جدیدتر نباشد رد می‌کند (پس نسخه‌ی امضاشده‌ی قدیمی را نمی‌توان دوباره فرستاد)، فقط فایل‌های خودش را می‌پذیرد (`index.php`، `.htaccess`، `src/*.php`)، نسخه‌ی قبل را در `backups/` نگه می‌دارد، فایل‌به‌فایل جایگزین می‌کند (`index.php` آخر) و در صورت هر خطا نسخه‌ی قبل را برمی‌گرداند. `data-location.php`، کد نصب و داده‌های شما دست نمی‌خورد.

* ایجنتی که **بدون** کلید عمومی ساخته شده (پیش‌فرض این مخزن) به‌روزرسانی را رد می‌کند و می‌گوید چرا؛ زیپ جدید را دستی آپلود کنید.
* هاستی که افزونه‌ی PHP به نام `sodium` ندارد نمی‌تواند امضا را تأیید کند (بررسی هاست می‌گوید).
* **هر که کلید خصوصی را داشته باشد روی همه‌ی ایجنت‌هایی که به آن اعتماد دارند می‌تواند کد اجرا کند.** آن را آفلاین نگه دارید، پشتیبان بگیرید و هرگز کامیت نکنید. برای چرخش کلید، نسخه‌ی امضاشده‌ای منتشر کنید که کلید عمومی تازه را دارد.

## بررسی این هاست

**هاست‌ها ← بررسی این هاست** خودآزمایی ایجنت را اجرا می‌کند (پوشه‌ی داده قابل‌نوشتن، rename اتمیک، قفل، symlink، باز کردن zip، محدودیت‌ها، sodium، درایور دیتابیس، Node، دسترسی خروجی HTTPS به wordpress.org، پوشه‌ی هر سایت) و از بیرون می‌سنجد که آیا وب می‌تواند `src/*.php`، `data-location.php`، `.htaccess` و پوشه‌ی داده را بخواند. هر خط یا خوب است یا هشدار یا خطا، با یک جمله‌ی ساده. روی هر هاست تازه و بعد از تغییر نسخه‌ی PHP اجرایش کنید.

## MCP: ابزار `studio`

کلاینت‌های هوش مصنوعی که با MCP وصل‌اند یک ابزار اضافه به نام **studio** برای پروژه‌های ایستای ساده دارند: فهرست هاست‌ها و پروژه‌ها، ساخت پروژه از قالب blank/landing، خواندن/نوشتن/حذف فایل‌های پروژه، فهرست نسخه‌ها، و (سطح *live* با تأیید دومرحله‌ای) انتشار و بازگشت. عمداً نمی‌تواند بیلد اجرا کند (بیلد اسکریپت‌های پروژه را روی کامپیوتر شما اجرا می‌کند)، به پروژه‌های Node یا فریم‌ورک دست بزند، وردپرس بسازد، اطلاعات محرمانه ببیند، متغیر محیطی بگذارد یا هاست را مدیریت کند. فقط به اتصال‌هایی داده می‌شود که به چند سایت وردپرس محدود نیستند.

## ماتریس تست

آنچه اینجا تأیید شده و آنچه به هاست واقعی نیاز دارد. هنگام امتحان روی هر هاست نتیجه را (حتی کوتاه) ثبت کنید.

| بخش | خودکار اینجا | نیازمند هاست واقعی |
|---|---|---|
| ویزارد نصب، ورود، قفل، 2FA، CSRF | تست واحد PHP و سرتاسری با `php -S` | HTTPS پشت پروکسی واقعی، LiteSpeed/nginx |
| API امضاشده، replay، سطوح | واحد و سرتاسری | اختلاف ساعت هاست و کامپیوتر |
| آپلود تکه‌ای، انتشار، بازگشت (sync) | سرتاسری، ۱۰ مگابایت چندتکه | `post_max_size` خیلی کم، اینترنت کند، `open_basedir` |
| حالت symlink | تست واحد هست؛ روی این ویندوز رد می‌شود | هر هاست لینوکس: `php agent/tests/run.php` را آنجا اجرا کنید |
| قواعد SPA | `.htaccess` تولیدی به‌صورت متن بررسی شد | Apache/LiteSpeed (AllowOverride FileInfo)، `try_files` در nginx |
| نصب وردپرس | دانلود ساختگی، config، فعال‌سازی بریج، جفت‌سازی | دانلود واقعی، API واقعی cPanel/DirectAdmin، MySQL واقعی |
| برنامه‌های Node | فایل، env، Passenger، نشانه‌ی ری‌استارت، اسکریپت (`bash -n`) | Passenger روی cPanel/Plesk/DirectAdmin، systemd روی VPS، Next زیر Passenger |
| به‌روزرسانی امضاشده | سرتاسری با ایجنت زنده (نیازمند `sodium`) | PHP هاست اشتراکی |
| فریم‌ورک‌ها | هر پنج قالب با npm ساخته شد | انتشار خروجی‌شان روی هاست |
| سازنده‌ی AI | مدل اسکریپتی | هر سرویس AI (کیفیت، پایداری JSON) |

اجرای اول پیشنهادی روی هاست تازه: زیپ را آپلود کنید، نصب، **بررسی این هاست**، قالب landing را منتشر کنید، بازگردانید، یک سایت وردپرس بسازید، یک پروژه‌ی React منتشر کنید.
